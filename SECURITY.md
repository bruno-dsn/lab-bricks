# Segurança deste projeto

Esta versão é uma demonstração pública com dados fictícios e um laboratório SQL de leitura em memória. Recebe apenas JSON restrito de progresso, sem gravar nem executar o arquivo. Não tem autenticação própria, banco de clientes, pagamento ou integração com contas Databricks. A biblioteca usa conteúdo versionado no repositório; a página de template só prepara downloads.

Se encontrar uma falha, evite publicar credenciais ou uma prova que exponha dados de terceiros. Num fork ou repositório seu, habilite um canal privado de relato no GitHub e siga as configurações disponíveis da plataforma. Este pacote não inventa um endereço privado de contato que ainda não existe.

Uma credencial enviada ao Git precisa ser revogada ou trocada no serviço correspondente; apenas apagar o arquivo não retira a cópia do histórico. Revise também logs, artifacts de CI e saídas de notebooks.

Leia [a auditoria desta versão](docs/AUDITORIA_SEGURANCA.md). Antes de expor dados reais ou recursos privados, implemente os controles dessa nova função e revise o ambiente concreto de hospedagem.
